# My Budget Tracker

## About the Project

My Budget Tracker is a simple web project created using HTML and CSS.

The project helps users understand and organize their expenses by displaying expense information in a clear table and providing a form for adding expense details.

## Features

- Add expense name
- Enter expense amount
- Select an expense category
- Display expenses in a table
- Show expense date
- Five sample expenses
- Interactive help section
- Budgeting tips section
- Image and YouTube video
- Hover effects
- Form input focus effects
- Responsive table styling

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub

## Expense Categories

The available categories are:

- Food
- Transport
- Rent
- Entertainment
- Other
