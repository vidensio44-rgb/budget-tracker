# My Budget Tracker

## About the Project

My Budget Tracker is a personal budget and expense tracking web application built using HTML, CSS, and JavaScript.

The project allows users to enter expense information and display it in an organized table. During Week 3, the main focus was improving the visual identity and user experience of the existing Budget Tracker using CSS.

## Week 3 Visual Design

The Budget Tracker was redesigned to create a clean, consistent, and user-friendly interface.

### Color Palette

A consistent color palette was applied throughout the application:

* Blue for buttons and table headers
* White for the main content cards
* Light gray-green for the page background
* Dark gray for main text
* Green for the total expenses section

These colors create a consistent visual identity across the application.

### Typography

Google Fonts are used to improve readability and visual hierarchy:

* **Poppins** is used for headings and table headers.
* **Inter** is used for body text, labels, form elements, and buttons.

The fonts are applied consistently throughout the application.

### Expense Form Styling

The Add Expense form was improved using CSS by adding:

* Proper spacing between form fields
* Padding inside input fields
* Borders around inputs
* Rounded corners
* Focus effects
* Consistent button styling
* Button hover effects

### Expense Table Styling

The expense table includes:

* Styled table headers
* Borders around table cells
* Padding inside cells
* Alternating row colors
* Row hover effects
* Consistent typography
* Responsive width

### CSS Box Model

The CSS Box Model was intentionally used throughout the project.

The main sections use:

* **Margin** to separate sections
* **Padding** to create space inside cards
* **Borders** to define content areas
* **Border-radius** to create rounded, modern cards

The following sections are displayed as distinct visual cards:

1. Page heading
2. Add Expense form
3. Expense table
